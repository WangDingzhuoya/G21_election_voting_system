PNG or JPG, maximum size 2 MB.

Writing Tips

A good profile is short and clear. Students often read only the first two lines, so put the main idea at the start of the biography.

Before You Add

  • Check the spelling of the student name.
  • Make sure the student ID is real.
  • Ask the person for a photo before publishing.
  • Read the biography out loud one time.
